## Course Description

This course introduces the fundamental concepts and principles of **Object-Oriented Programming (OOP)**. Students will learn how to think in an object-oriented way — modeling real-world problems as interacting objects — and understand the four core pillars: **Encapsulation, Inheritance, Polymorphism, and Abstraction**. Java is used solely as a vehicle to illustrate and practice these concepts. All topics are kept at the **introductory level**. Advanced OOP topics (SOLID Principles, Design Patterns, Generics, Streams) are covered in the follow-on course.
